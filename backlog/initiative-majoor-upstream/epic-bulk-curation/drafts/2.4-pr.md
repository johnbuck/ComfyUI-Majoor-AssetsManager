**Title:** feat: rate multi-card selections in one batch

Part of #ISSUE (bulk tag and rating edits). The tags half is a separate PR.

### What changed and why

The 0–5 hotkeys sent one `POST /mjr/am/asset/rating` per selected card, at concurrency 5, against a
30-per-minute limit, so large selections failed partway. "Set rating" only rated the right-clicked
card.

**Backend**

- `POST /mjr/am/assets/rating {ids, rating}` (`routes/assets/route_actions_batch_rating.py`):
  - **Validation and limits.** The rating goes through the existing `parse_rating_value` (clamped
    0–5). Ids are deduped and capped at 500; the route allows 10 requests per minute.
  - **Writes.** A chunked existence check runs first. Then each asset goes through the existing
    `update_asset_rating` (per-asset lock plus the Comfy-core write-through). The ExifTool sync is
    enqueued only for updated ids.
  - **Partial results.** `{updated_ids, failed: [{id, code, error}], rating}`, with one audit entry
    per request.
- `security_policy.py`: `assets_rating` is gated exactly like `asset_rating`. Safe mode otherwise
  refuses unknown operation names.

**UI**

- `ui/features/grid/bulkRating.ts` (new) sends sequential 500-id chunks.
  - Badges update from `mjr:asset-rating-changed` for confirmed ids only, using the server's applied
    rating.
  - Ids that aren't confirmed count as failed.
  - One summary toast appears, plus progress for multi-chunk runs.
  - Runs are serialized and the last one wins, so rapid key presses or clicks never interleave.
- **Hotkeys.** With 2 or more cards selected, the hotkeys use the batch. A single card uses the
  existing path, unchanged.
- **Menu.** "Set rating (N selected)" appears when the right-clicked card is part of the selection.
  Otherwise the single-card submenu is unchanged.

### How to test

- pytest:
  - validation, clamping, missing ids, the cap and the rate limit;
  - sync enqueue only for updated ids, and the audit entry;
  - a test against the real safe-mode gate.
- Vitest (`bulk_rating.vitest.ts`, plus additions to `rating_hotkeys.vitest.ts`):
  - chunking, partial results, unconfirmed ids and the server-clamped rating;
  - latest-wins serialization;
  - menu gating for selected vs unselected right-clicks;
  - the hotkeys' single vs multi path.
- Manual: select 200 cards and press 4. All are rated, and their badges update.
